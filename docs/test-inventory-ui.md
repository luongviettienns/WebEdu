## 2. Danh Mục Kiểm Thử Đa Trình Duyệt, Kích Thước Màn Hình & Khả Năng Truy Cập (Accessibility)

1. **Đa trình duyệt (Cross-Browser)**: `Chromium`, `Firefox`, `WebKit`.
2. **Đa kích thước màn hình (Responsive Viewports)**: `375x812` (Mobile), `768x1024` (Tablet), `1024x768` (Small Laptop), `1440x900` (Desktop). Kiểm tra `scrollWidth <= innerWidth` (không tràn ngang).
3. **Khả năng truy cập (`@axe-core/playwright`)**: Quét tự động trên từng trang, yêu cầu **0 lỗi mức `serious` / `critical`**, kiểm tra điều hướng phím `Tab`, `:focus-visible`, và liên kết `<label for="...">`.
4. **Chữ Hán / Pinyin & Unicode**: Kiểm tra hiển thị font chữ Hán (`Noto Serif SC` / system CJK), dấu thanh điệu Pinyin (`Hànyǔ Shuǐpíng Kǎoshì`), nhập và lưu tiếng Việt + chữ Hán không lỗi encoding.
