# Prompt khởi động ngữ cảnh dự án cho AI Coding Agent

Dán nội dung dưới đây khi bắt đầu một phiên Agent mới trong repository WebEdu, sau khi đã copy thư mục Project Context vào repo hoặc đảm bảo agent có quyền đọc nó.

---

Bạn đang hỗ trợ phát triển **TD Hán Ngữ / WebEdu**. Trước khi đề xuất hoặc sửa code, hãy đọc theo thứ tự:

1. `PROJECT_CONTEXT.md`
2. `AGENTS.md`
3. `docs/01-business/decision-log.md`
4. `docs/01-business/business-rules.md`
5. `docs/01-business/roles-permissions.md`
6. `docs/01-business/open-issues.md`
7. `docs/02-requirements/function-catalog.md`
8. Module docs liên quan trong `docs/02-requirements/modules/`
9. Codebase thực tế, cấu trúc repo và các test hiện có.

Bắt buộc áp dụng quyết định mới ngày **06/11/2026**: học viên dưới 16 tuổi do người giám hộ đăng ký thay và sử dụng **email phụ huynh thay SĐT phụ huynh**. Không suy đoán email phụ huynh đồng thời là email đăng nhập hay quy tắc unique nếu chưa được chốt.

Các vấn đề công thức điểm, scoring, rubric, mẫu đề Word/PDF là **TBD-DEFERRED**: để đến đúng module mới xử lý; không chặn các module độc lập. Không tự tạo business rule cho các phần này. Không thêm tính năng ngoài Phase 1; không phát triển AI chấm tự luận, tuyển sinh, thanh toán online hoặc account phụ huynh riêng.

Review prototype chỉ phản ánh UI mockup, **không** chứng minh đã có backend hoặc production-ready code. Kiểm tra repository thực tế trước mọi nhận định. Nếu codebase và docs mâu thuẫn, báo phát hiện rõ ràng; không tùy tiện đổi quyết định nghiệp vụ.

**Yêu cầu đầu tiên:** chưa code ngay; hãy tóm tắt 1) kiến trúc thực tế của repo, 2) trạng thái các FUNC trong module sắp làm, 3) vấn đề chặn triển khai, 4) plan thay đổi file/schema/API/tests. Chỉ code khi task cụ thể và các quyết định cần thiết đã rõ.
